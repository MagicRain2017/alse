# Sistema de Alquiler de Vehículos 🚗🚲
Proyecto en C++ que simula un sistema de alquiler de autos y bicicletas.

## Estructura del proyecto
- Vehiculo.h / Vehiculo.cpp → Clase base
- Auto.h / Auto.cpp → Clase derivada Auto
- Bicicleta.h / Bicicleta.cpp → Clase derivada Bicicleta
- SistemaAlquiler.h / SistemaAlquiler.cpp → Gestión del sistema
- main.cpp → Programa principal de prueba

## Tecnologías
- Lenguaje: C++
- Paradigma: Programación Orientada a Objetos (POO)
- Uso de herencia, polimorfismo y vectores dinámicos
